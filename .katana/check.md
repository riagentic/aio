# aio check for each release before it's released

## Criteria

- current version is objectively better than the previous one
- current version doesn't contain any regression
- current version is more intuitive than the previous one
- current version is more architecturally sound than the previous one
- current version has better or same API than the previous one
- current version fixes or improves previous version significantly
- current version is more user friendly
- current version is better documented than the previous one
- current version is less bloated than the previous one
- current version is more developer friendly than the previous one
- current version is more polished than the previous one
- current version has overall better test coverage than the previous one
- current version is easy pick over the previous one
- current version provides simpler usage than the previous one
